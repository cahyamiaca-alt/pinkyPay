Hosting & Domain Publik (Online)

Akses PinkyPay dari mana saja melalui link internet umum

Alamat Web Saat Ini Aktif
http://localhost:3000

1 Link Online Cepat (Gratis Tanpa Bikin Akun)

Cepat

Buka terminal baru di folder proyek dan ketik:

npm run share

Perintah ini akan langsung membagikan web ke internet melalui link publik HTTPS (contoh: https://pinkypay-mia-peter.loca.lt) yang bisa dibuka dari HP mana saja!

2 Deploy Permanen 24/7 Gratis (Render / Vercel)

Permanen

Proyek ini sudah dilengkapi konfigurasi cloud siap pakai: render.yaml dan vercel.json.

  1. Upload folder proyek ini ke GitHub.
  2. Buka render.com atau vercel.com (gratis).
  3. Pilih New Web Service dari repository GitHub Anda.
  4. Dapatkan link permanen seperti https://pinkypay.onrender.com yang aktif selamanya!

Pasang PinkyPay Sebagai Aplikasi

Buka langsung dari layar utama HP / Komputer tanpa browser

PinkyPay Mobile & Desktop App

Mendukung PWA Standalone, Notifikasi, Offline & Realtime Sync

🍎 Pengguna iPhone / iPad (Safari):
  1. Buka web ini di browser Safari iPhone Anda.
  2. Ketuk tombol Bagikan (Share) 📤 di bilah navigasi bawah Safari.
  3. Gulir ke bawah lalu pilih menu "Tambah ke Layar Utama" (Add to Home Screen) ➕.
  4. Ketuk "Tambah" (Add) di pojok kanan atas. Ikon PinkyPay akan otomatis terpasang seperti aplikasi dari App Store!
